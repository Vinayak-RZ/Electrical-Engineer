## Objective

`docs/ui-ia.md` describes persistent workspace: runs list, run detail, library SVG/PNG, photo confirm, RAG inventory, memory excerpts, gate prompt. Slots: `root`, `sidebar`, `workspace`, `run.detail`, `run.artifacts`, `photo.confirm`, `rag.inventory`, `memory.excerpt`, `gates.prompt`. States: empty, running, waiting-human, failed, done. WCAG AA. Not KiCad. Not a second agent. CSR Vite SPA served by FastAPI on 127.0.0.1. Zustand for layout + current run. CSS tokens, no MUI/Ant. Register API inspired by DSH `slots.register` — **our** 50-line registry, not Cordis.
