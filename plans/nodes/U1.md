## Objective

`docs/ui-ia.md` describes persistent workspace: runs list, run detail, library SVG/PNG, photo confirm, RAG inventory, memory excerpts, gate prompt. Slots: `root`, `sidebar`, `workspace`, `run.detail`, `run.artifacts`, `photo.confirm`, `rag.inventory`, `memory.excerpt`, `gates.prompt`. States: empty, running, waiting-human, failed, done. WCAG AA. Not KiCad. Not a second agent. CSR Vite SPA served by FastAPI on 127.0.0.1. Zustand for layout + current run. Register API inspired by DSH `slots.register` — **our** 50-line registry, not Cordis.

**Visual system (normative):** [`docs/design/DESIGN-coinbase.md`](../../docs/design/DESIGN-coinbase.md). U1 must publish a token map (CSS variables) and EE component mapping — do not invent a second palette.

- Canvas white `#ffffff`; ink `#0a0b0d`; single action color `#0052ff` (scarce: primary pills + focus + inline links only).
- Display weight **400**; numbers in mono (`number-display`); CTAs `{rounded.pill}`; cards `{rounded.xl}` 24px; no sharp CTA corners.
- Depth: hairline + one soft shadow tier; card-on-card, not decorative shadow stacks.
- Fonts: **Inter** (display+body) and **JetBrains Mono** or **Geist Mono** (numbers). Never commit Coinbase Display/Sans/Mono/Icons or the Coinbase wordmark.
- Workspace density: use the token scale, not 96px marketing section padding on every chrome row. Optional dark `surface-dark` band for the current-run hero only.
- EE semantics: checked numeric text → `semantic-up` (text only); failed → `semantic-down` (text only); `unchecked` → `badge-pill` (not a red/green button); confirm topology → `button-primary`; run list → `asset-row`; inputs → `text-input` with 2px primary focus.
- Breakpoints and 44px CTA height from the design file. No MUI/Ant/Tailwind-as-architecture.
