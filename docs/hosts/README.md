# Host adapters

Electrical Engineer is a local CLI + stdio MCP server. Cursor, Claude Code, and
OpenAI/Codex are **first-class hosts**, not the only way to run it.

Install the host’s skill by copying or symlinking `skills/<pack>/SKILL.md`.
Point stdio MCP at:

```text
electrical-engineer mcp
```

There is no `init-host` helper (ponytail). Students need not use Cursor.

- [OpenAI / Codex](openai.md)
